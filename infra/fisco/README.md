# Local FISCO BCOS

`setup.sh` downloads FISCO BCOS and its console into `build/` (gitignored), builds a four-node chain on 127.0.0.1 with the web3 JSON-RPC on port 8545, and registers the admin account as balance governor. `start.sh` and `stop.sh` restart and stop the nodes. The full guide is [`docs/guides/fisco-bcos.md`](../../docs/guides/fisco-bcos.md).
